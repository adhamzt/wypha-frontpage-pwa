SEBELUM ANDA MEMESAN

Hal kecil yang perlu diketahui.

Detail pesanan disepakati lebih dulu supaya hadiah Anda sesuai harapan.

Perlu install aplikasi? ⌄

Tidak wajib install! Cukup scan QR menggunakan kamera HP dan halaman cerita langsung terbuka di browser. Namun, jika diinginkan, halaman ini juga mendukung fitur PWA (Progressive Web App) sehingga bisa disimpan ke layar utama HP seperti aplikasi.

Foto seperti apa yang perlu dikirim? ⌄

Cukup kirimkan 1–5 foto wajah yang jelas (pencahayaan terang dan tidak buram) beserta nama panggilan dan cerita singkat yang ingin dimasukkan lewat WhatsApp.

Bagaimana ketentuan revisinya? ⌄

Kami mengirimkan preview desain karakter, teks cerita, dan tampilan microsite terlebih dahulu untuk Anda setujui sebelum proses cetak akrilik/poster dimulai.

Berapa lama cerita bisa dibuka? ⌄

Masa aktif standar nasional adalah 10 Tahun, dan khusus alamat pengiriman di wilayah kabupaten lokal kami mendapatkan Program Kado Warga Lokal hingga 18 Tahun (sampai anak dewasa).

Berapa lama pengerjaan dan pengiriman? ⌄

Pengerjaan ilustrasi personal & halaman cerita rata-rata 1–3 hari kerja setelah foto diterima, dilanjutkan pencetakan 300 PPI dan pengiriman ke alamat Anda.

Bisa request konsep sendiri? ⌄

Sangat bisa! Anda dapat memilih tema dari galeri #koleksi atau meracik ide konsep impian Anda sendiri bersama tim WYPHA PrintLab.

Pusat Deployment PWA (GitHub ➔ Cloudflare Pages) & Google Sites Embed

Semua file yang dibutuhkan agar studio & halaman muka V3.0 ini menjadi aplikasi Progressive Web App (PWA) utuh di Cloudflare Pages sudah disiapkan otomatis di bawah ini.

1. Upload ke GitHub Repo

Masukkan file index.html, manifest.json, sw.js, dan _headers ke repository GitHub Anda.

2. Connect Cloudflare Pages

Buka Cloudflare Dashboard ➔ Workers & Pages ➔ Create ➔ Pages ➔ Connect to Git. Pilih repo GitHub Anda (Build command kosongkan, output directory: /).

3. Sematkan di Google Sites

Jika tetap ingin memakai domain Google Sites, gunakan menu Insert ➔ Embed ➔ Embed Code lalu tempel snippet iframe responsif di bawah.
